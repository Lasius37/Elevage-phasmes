Entretenir l’élevage

Un élevage de Carausius morosus demande un entretien régulier afin de maintenir de bonnes conditions de vie pour les phasmes. Quelques gestes simples permettent d’assurer leur santé, leur croissance et leur reproduction.

Vérifier les végétaux

Les feuilles constituent la nourriture principale des phasmes. Il faut donc vérifier régulièrement leur état.

Les végétaux fanés, secs ou moisis doivent être remplacés rapidement. Les branches fraîches permettent aux phasmes de se nourrir correctement et de rester hydratés.

La ronce reste généralement le végétal le plus pratique pour l’élevage.

Contrôler le récipient d’eau

Le récipient contenant les branches doit rester rempli d’eau afin de conserver les feuilles fraîches plus longtemps.

Il faut également vérifier que le système de sécurité empêchant les jeunes phasmes de tomber dans l’eau reste bien en place.

Maintenir une bonne humidité

Une légère humidité est importante, surtout pour les jeunes phasmes et pendant les périodes de mue.

Une pulvérisation légère d’eau peut être réalisée sur les parois ou les feuilles lorsque l’air devient trop sec.

Le vivarium ne doit cependant pas devenir détrempé, car un excès d’humidité favorise les moisissures.

Observer les phasmes

L’observation régulière permet de détecter rapidement d’éventuels problèmes.

Un phasme en bonne santé :

  • grimpe normalement ;
  • mange régulièrement ;
  • réalise ses mues correctement ;
  • présente un corps intact et bien formé.

Un individu immobile au sol, déformé ou incapable de grimper peut rencontrer des difficultés.

Nettoyer le vivarium

Des déchets s’accumulent progressivement dans le vivarium :

  • crottes ;
  • feuilles mortes ;
  • anciennes mues ;
  • œufs.

Un nettoyage régulier permet de limiter les moisissures et de maintenir un environnement sain.

Le fond du vivarium peut être remplacé facilement s’il est constitué de papier absorbant ou de papier journal.

Récupérer les œufs

Les femelles laissent tomber leurs œufs au sol. Ceux-ci peuvent être récupérés lors du nettoyage.

Les œufs peuvent ensuite être :

  • laissés dans le vivarium ;
  • placés dans une boîte d’incubation ;
  • conservés pour de futurs élevages.

Surveiller les mues

Les mues sont des étapes délicates du développement. Le phasme doit pouvoir se suspendre librement pour sortir correctement de son ancien exosquelette.

Il est important de :

  • laisser suffisamment d’espace vertical ;
  • éviter les manipulations pendant les mues ;
  • maintenir une légère humidité.

Une mauvaise mue peut entraîner des déformations ou la mort du phasme.

Éviter les dangers

Plusieurs éléments peuvent être dangereux pour les phasmes :

  • les produits chimiques ;
  • les insecticides ;
  • les fortes chaleurs ;
  • un manque d’humidité ;
  • des végétaux traités.

Le vivarium doit être installé dans un endroit calme, à température stable et sans exposition directe au soleil.

Manipuler les phasmes

Les phasmes sont fragiles et doivent être manipulés avec précaution.

Pour les déplacer, il vaut mieux :

  • laisser l’animal grimper seul sur une main ou une branche ;
  • éviter de tirer sur les pattes ;
  • manipuler doucement et calmement.

Les jeunes phasmes sont particulièrement délicats.

Fréquence de l’entretien

Certaines tâches doivent être réalisées très régulièrement :

  • vérification des feuilles : presque tous les jours ;
  • contrôle de l’eau : tous les jours ;
  • pulvérisation légère : selon l’humidité ;
  • nettoyage partiel : chaque semaine ;
  • nettoyage plus complet : régulièrement selon la taille de l’élevage.
